    Driver Help

    WebUSB needs a WinUSB driver for the DFU device.

    • Windows x64: Install with Zadig (Options → List All Devices → select STM32 BOOTLOADER → Replace Driver).
    • Windows on ARM: Zadig does not work. Flash from another OS, or install WinUSB manually. See README for details.

    Known issue: Windows on ARM Chromium browsers have severe USB transfer slowdowns (see Chromium issue 494543570).
